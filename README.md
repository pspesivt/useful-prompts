## Editing a prompt

The prompts live on [Bikeshed](https://bikeshed.now), which holds their source and version history. This repo only holds the hub page and a redirect from the old GitHub Pages URL.

To edit one, run `bikeshed get <id> > <file>`, change the file, then run `bikeshed update <id> <file>`. Each update blocks the document's scripts until someone trusts it again in the app, so the copy button stays hidden until then.
